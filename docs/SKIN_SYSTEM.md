# BA仔皮肤系统

皮肤不是临时图片替换，而是 BA仔身份的一部分。每一套都应保留这些识别点：黑白花、右侧头顶深色花纹、大眼睛、小肉垫、蓬松轮廓、深色尾巴，以及带紫色爱心的王冠。

## 新增皮肤的步骤

1. 准备一张有真实透明通道的 PNG，建议不低于 1024px，四周留白，主体居中。
2. 维持头像的扁平手绘线条；不要使用照片感、3D、闪亮塑料质感或带底色的方图。
3. 将文件放到 `src/assets/skins/`，用稳定的英文小写文件名。
4. 在 `src/App.tsx` 的 `skins` 中加入图片、名称和一句描述。
5. 切换皮肤后检查待机、聊天、专注、踢球四种动画和窄窗口布局。
6. 运行 `npm run verify`，再在 Windows 的 100% 与 150% 缩放下确认轮廓清晰。

## 动作资产的后续约定

下一阶段若改为逐帧动画，每套皮肤应放入单独文件夹，包含 `idle`、`talk`、`focus`、`celebrate`、`kick` 五个动作。先保留相同的锚点和画布比例，再替换渲染方式；不要让业务逻辑依赖某一张皮肤的文件名。
