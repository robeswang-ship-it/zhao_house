# BA仔 · 小猫管家

送给她的 Windows 桌面小管家。BA仔是一只可换皮肤、会聊天、会提醒日程、陪伴番茄钟并在本地保存生活记忆的小猫。项目设计为本地优先、源码清晰，方便任何本地 Agent 后续维护。

## 已打通的第一版

- 真正的双窗口桌宠：默认是透明、置顶、可拖动的 BA仔悬浮窗；点小猫才打开完整小管家面板
- 系统托盘：左键唤醒面板，菜单可暂时隐藏、居中找回 BA仔 或退出；拖动位置会在本地记住
- 待机、聊天、专注和踢球时会有不同动作
- 签名自动更新：启动时静默检查，设置页由用户确认下载、安装与重启；更新包不需要 GitHub 登录
- 两套可一键切换且会记住选择的手绘皮肤：女王花猫、雪天女王
- 本地 SQLite：日程、番茄钟、记忆和聊天记录均保存在设备上
- 安全地保存在系统凭据存储中的 OpenAI API 密钥（不写入安装包）
- AI 聊天：会带入近期日程、番茄钟统计和本地记忆摘要
- 文字日程解析和 Excel 本地导入预览，写入前由用户确认
- 日程清单、番茄钟、纪念日倒计时、豆包踢球彩蛋

## 本地运行

```bash
npm install
npm run tauri dev
```

需要 Node.js、Rust 和平台对应的 Tauri 开发前置条件。Mac 上负责开发；发布 Windows 版本时由 `.github/workflows/windows-release.yml` 在 Windows 环境生成安装包。

## 数据位置与安全

- 应用数据由 Tauri 放在系统的本地应用数据目录；安装或升级不会覆盖它。
- API 密钥通过系统凭据存储保存，前端与数据库都不会读取到明文。
- 聊天请求使用 `store: false`；仍请只把需要回答的问题和必要的本地上下文交给模型。
